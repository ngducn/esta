# Photos

Demo property covers from Pexels (Pexels License, attribution optional; authors in the app repo's `supabase/seed/photos/ATTRIBUTION.md`), 640px WebP. Use them only for the property card's photo slot in mockups, cropped 16:10 with `object-fit: cover`. Real family photos never go into this system.

- `day-tro.webp` — low-rise block with long balconies (Dãy trọ Dĩ An Demo).
- `can-ho.webp` — high-rise apartment towers (Căn hộ Thảo Điền Demo).
- `nha-pho.webp` — teal three-storey tube house (Nhà phố Gò Vấp Demo).
- `dat.webp` — dirt track beside a fenced field (Đất Long An Demo).
