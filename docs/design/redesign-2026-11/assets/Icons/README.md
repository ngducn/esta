# Icons

The 29 Lucide glyphs Esta's shell and statuses use most, copied from `lucide-react` 1.57.0 (ISC). Each file is 24×24, 1.75 stroke, single ink `text` `#1b1816` (an `<img>` cannot inherit colour). In code, prefer `Esta.icon(name)` or `<i data-icon="name">`, which draw the same paths in `currentColor`; `Esta.icons` lists all 71 names available.

Navigation: `house` (Tổng quan), `building-2` (Tài sản), `banknote` (Thu tiền), `file-text` (Tài liệu), `message-square-text` (Trợ lý), `chart-column` (Báo cáo), `settings` (Cài đặt). Status: `circle-check` paid, `clock` due soon, `triangle-alert` overdue, `circle-dashed` empty, `pencil-line` draft, `archive` ended. Actions: `plus`, `check`, `x`, `search`, `bell`, `calendar`, `camera`, `qr-code`, `zap` (meter readings), `map-pin` (current address), `scroll-text` (address on the sổ).
